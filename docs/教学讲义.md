## 第 1 讲 · 神经元与网络：它到底在算什么

**一个神经元 = 一次加权打分。**

想象你判断一道菜好不好吃：油多(-1分)、辣(你自己爱吃+2分)、新鲜(+3分)……
把每项打分乘以你的"在意程度"再加总，超过某个阈值你就说"好吃"。
神经元就是这个过程：`输出 = 激活函数(Σ 输入×权重 + 偏置)`。

- **权重 (weight)**：每个输入的"在意程度"，**学习 = 学这些数**
- **偏置 (bias)**：基础分，决定多容易"被激活"
- **激活函数**：加点非线性。没有它，一百层线性叠起来还是线性的，学不了复杂规律

一层神经元排成数组，就是矩阵乘法：`输出向量 = 输入向量 @ W + b`。
所以"前向传播"本质上就是**两次矩阵乘法夹一个 sigmoid**，见 step1 的 `forward()`。

**为什么是 784-30-10？**
输入 784 = 28×28 个像素（视频原版设定）；输出 10 = 0~9 十个类；
隐藏层 30 个神经元是"中间理解层"——太少学不会，太多记性好但死记硬背（过拟合）。

## 第 2 讲 · 损失函数：怎么量化"错得多离谱"

模型输出 10 个概率（softmax 把任意得分变成合法概率分布）。
正确答案是 3，模型说"3 的概率 0.9"→ 好模型；说"0.001"→ 烂模型。

**交叉熵损失** 把这个直觉变成一个数：

```
loss = -log(模型给正确答案的概率)
```

| 模型给正确答案的概率 | loss |
|---|---|
| 0.99（很有信心且对了） | 0.01 |
| 0.5  | 0.69 |
| 0.1  | 2.30 |
| 0.001（很自信地错了） | 6.9 |

特点：**对→几乎不罚，错→指数级重罚**。这正是我们想要的驱动力。

## 第 3 讲 · 梯度下降与反向传播：怎么"学"

**山丘比喻**：损失是一座山，参数是你站的位置，目标是走到谷底。
你看不见全貌，只能感觉到脚下的坡度（=梯度），于是往**下坡方向**迈一小步：
`参数 -= 学习率 × 梯度`。走几百万步，就到谷底了。

- **学习率**：步子大小。太大→来回跳过谷底（损失震荡）；太小→十年走不到。
- **批量 (batch)**：一次用几张图估计坡度。批量越大越准但越贵；小批量带一点噪声，反而有助于跳出小坑。

**反向传播 (backpropagation)** 是高效算梯度的算法，就两句话：

1. **前向传播**时把每层的中间结果记下来；
2. 从损失出发，**用链式法则把"责任"逐层往回传**：
   - 输出层：`误差 = 预测 - 答案`（softmax+交叉熵求导的漂亮结论）
   - 往回传：`上一层的责任 = 本层的责任 @ Wᵀ`，再乘上激活函数的导数
   - 每个权重的梯度 = "它的输入" × "它参与的那个神经元的责任"

一句话总结：**每个权重对最终错误负多大责任，就按多大比例改它。**
完整推导落在 step1 的 `train_step()` 注释里，逐行对照看。

> 视频/书里 2012 年用"二次代价 + sigmoid"是因为推导简单，
> 现在（以及本项目）都用"交叉熵 + softmax"：求导更干净、收敛更快、不会饱和。

## 第 4 讲 · 三大经典问题与对策

### 过拟合 Overfitting（Step 2 实测出现）
训练集 99.5%、验证集 97.8% → 模型在**背题**而不是**解题**。
对策：更多数据、数据增强、Dropout（step3）、正则化、早停 (early stopping)。

### 梯度消失 Vanishing Gradient
sigmoid 的导数最大只有 0.25，深层网络逐层相乘后梯度趋近 0，底部层学不动。
对策：ReLU（导数恒为 1，不会缩小）、残差连接（ResNet）、BatchNorm。

### 数据泄露 Data Leakage
用测试集调参/算均值 → 分数虚高。**验证集调参，测试集只考一次**，刻在脑子里。

## 第 5 讲 · 为什么 CNN 能到 99% 而 MLP 到不了

MLP 把图拉平，一个像素挪动一格 = 全新的输入，且 784 个输入每个都要单独学。
CNN 的两个设计直接编码了"图像"的先验知识：

1. **局部感受野**：3×3 卷积核只看局部 —— 而"笔画"本来就是局部的；
2. **权重共享**：同一个探测器扫遍全图 —— "竖线"出现在左上还是右下都能检出。

然后逐层组合：边缘 → 笔画 → 局部形状（圈、钩）→ 整字。
这个"层次化特征"的思路后来被 ViT、各种大模型继承，只是把"卷积"换成了"注意力"。

## 第 6 讲 · 2012 年的代码 vs 现代写法（本项目改了什么）

| 2012 原仓库 | 本项目 / 现代做法 | 原因 |
|---|---|---|
| Python 2 + Theano | Python 3.14 + PyTorch | Theano 2017 年停止维护；PyTorch 是当前主流研究/工业框架 |
| 二次代价 + sigmoid 输出 | 交叉熵 + softmax | 求导干净、收敛快、不饱和 |
| 手写反向传播（教学用） | autograd 自动微分 | 不易出错，且能表达任意结构；但**建议先手写一遍**再享受框架 |
| 固定学习率 3.0 | Adam 自适应学习率 | 少调参；大模型时代 AdamW 是标配 |
| CPU / 单线程 | GPU 并行（你的 RTX 5070） | 大规模矩阵乘法快几十倍，是深度学习革命的一半 |
| 无随机种子管理 | `seed` 固定，可复现 | 科学严谨性，别人能复现你的结果 |

## Link this repository to an existing local folder (Windows)

If your project already exists at:

`C:\Users\ASUS-PC\Desktop\files\code\machine_learning\gradual_descend`

run these commands in **PowerShell**:

```powershell
cd "C:\Users\ASUS-PC\Desktop\files\code\machine_learning\gradual_descend"
git init
git remote add origin https://github.com/huuskihu/gradual_descend.git
git fetch origin
git branch -M main
git add .
git commit -m "Initial local files"
git pull origin main --allow-unrelated-histories
```

If `origin` already exists, use:

```powershell
git remote set-url origin https://github.com/huuskihu/gradual_descend.git
```
